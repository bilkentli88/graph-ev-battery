# Results

The `raw/` directory contains outputs generated by the completed neural experiment notebooks. Seed-level rows and topology-permutation rows are repeated measurements and must not be treated as independent product-level observations.

For inference, the held-out battery product is the independent experimental unit (`n=10`). Neural-training seeds are averaged within product, and the five semantic-topology permutations are additionally averaged within product before real-versus-permuted comparisons.

## Primary manuscript statistics

`paper_paired_statistics.csv` contains rounded product-level statistics for the primary capacity and topology-mechanism comparisons. Exact computations should use the corresponding fold-level CSV files in `raw/`.

## No-progress sensitivity

`no_progress_sensitivity_paired.csv` contains the product-level contrasts, 95% product-bootstrap intervals, exact paired sign-flip p-values, and primary Hits@1 Holm-adjusted topology p-values after normalized sequence progress is removed from the scoring head.

The underlying neural outputs are:

- `raw/no_progress_sensitivity_seed_results.csv`
- `raw/no_progress_sensitivity_fold_mean.csv`

This analysis is a robustness check; it is not treated as an additional independent confirmatory experiment family.

## Uniform-random baseline

`random_baseline.csv` contains the analytical expectation under uniform random ranking at each decision state. The calculation uses the state-specific candidate-set size and the same within-product and across-product averaging as the neural-model results. No training is involved.

## Other derived results

- `singleton_sensitivity.csv`: deterministic removal of the one-candidate terminal state.
- `individual_permutations.csv`: diagnostics for the five individual semantic-topology permutations.
- `structural_associations.csv`: exploratory structural association diagnostics.
- `recomputed_statistics.txt`: console output from `scripts/recompute_statistics.py` for the current repository snapshot.
